# Security Policy

## Supported Versions

Only the latest published version receives fixes.

## Reporting a Vulnerability

Report it through GitHub's private vulnerability reporting:
**[Open a private vulnerability report](https://github.com/anilcancakir/magic_analytics/security/advisories/new)**

The report stays confidential until a fix is ready. Include the affected version, the platform, and the steps to reproduce. For personal data that reached Google Analytics, name the event or parameter it appeared in.

## Scope

This policy covers the `magic_analytics` package: the `Analytics` facade, its web (GTM), mobile (Firebase) and null drivers, and consent handling. Issues in `firebase_analytics`, `firebase_core`, Google Tag Manager, the Magic framework and the Flutter SDK belong to their maintainers.
